## AntiMouse

<img src="src/main/resources/icon.png" alt="icon" />

### Что это?
* Перестала работать мышь?
* Глючит тачпад?
* Просто любите vim?

Тогда эта программа для вас. Программа позволяет управлять мышью с клавиатуры

### Использование
* Если отсутствует java, установить Java Runtime https://www.java.com/en/download/manual.jsp
* Установить AntiMouse # порядок установки
* Запустить # описание запуска

### Как управлять мышью с клавиатуры:
* Двойное нажатие Ctrl вызывает окно программы, которое будет принимать нажатия
  клавиатуры и преобразовывать их в движения мышью
* Отпускание Ctrl вызывает "клик", если удерживать Alt, при отпускании,
  то клик не будет выполнен
* Двойной клик вызывается при отпускании Ctrl с удержанием Shift
* Управлять движением курсора можно через клавиши HJKL или WASD
* Замедлять и ускорять курсор можно клавишами Shift и Alt + Shift соответственно
* Удержание Alt и нажатия кнопок вертикального направления движения, вызывает прокрутку
* Удержание клавиши "Пробел", переводит управление в ForceMod, когда мышь будет
  эмулироваться даже если окно не получило фокус (полезно, когда несколько программ
  запускают окна "поверх всего")
* Конфигурация находится в домашней директории, в файле .anti-mouse.conf

### В перспективе
* не реализован клик правой кнопкой
* прокрутка выполняется только множеством нажатий

### Баги
* При выходе из режима forceMouse без использования frame, отсутствует сброс состояния модификатора
  (может ещё чего-то)
